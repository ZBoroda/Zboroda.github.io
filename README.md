# Zboroda.github.io

Personal website and portfolio for Zachary Boroda, hosted via GitHub Pages at [zboroda.github.io](https://zboroda.github.io).

## About

A single-page personal site covering work experience, education, research, and outside interests. Built with HTML, CSS, and Bootstrap 5.

## Structure

```
index.html        # Main single-page site
styles.css        # Custom styles (Bootstrap + custom theme)
sitemap.xml       # Sitemap for search indexing
images/           # Profile photo and favicon
files/            # CV (PDF)
```

## Stack

- HTML/CSS with [Bootstrap 5](https://getbootstrap.com/)
- [Google Fonts](https://fonts.google.com/) (Lora + Inter)
- Hosted on [GitHub Pages](https://pages.github.com/)
